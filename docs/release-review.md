# 11단계 독립 리뷰와 수정 검증

2026-10-28. 실행 계획의 마지막 독립 리뷰 1회로 전체 221파일 변경을 검사했다. 범위는 `96768eb..faece86`, 리뷰어는 별도 문맥의 gpt-6-astra다. 리뷰어는 읽기 전용으로 동작했고 코드·DB·브라우저·유료 API를 변경/실행하지 않았다. 수정 후 재리뷰를 받은 것으로 표현하지 않으며, 아래 재현·회귀 검사는 구현자가 실행했다.

## 결과

Critical 0건, Important 2건, 보류할 Minor 0건. 중요한 두 건은 원래 코드에서 재현한 뒤 한 번의 수정 작업으로 해결했다. 전체 재검사 결과는 [인수 기록](acceptance.md)에 별도로 기록한다. 현재 UI·기기 환경이 없으므로 공개 릴리스 승인은 남아 있다.

### 이미 지난 시각으로 변경한 미발송 작업

이전 `008_notification_outbox.sql`의 재예약 함수는 새 발송일과 같은 날짜의 작업만 갱신했다. 오늘 작업이 pending/retry/leased 상태인데 시각을 과거로 바꾸면 설정에는 내일이라고 표시되지만 오늘의 옛 작업이 발송될 수 있었다.

실제 DB 회귀 테스트 `time_change_to_past_retires_today_entirely_unsent_jobs_and_invalidates_leases`가 기존 코드에서 pending/lease가 남는 것으로 실패했다. 추가 마이그레이션 `009_release_recovery.sql`에서 이전 날짜의 완전 미발송 작업을 skipped로 바꾸고 임대 토큰을 지운다. 이미 일부 기기에 전송한 작업은 기존 정책대로 나머지 구독만 재시도한다. 이전 함수가 남긴 잘못된 작업도 마이그레이션 때 정리한다. 적용된 008을 덮어쓰지 않는다.

### 서버 중단 후 영수증 분석 복구

분석 시작은 DB에 analyzing을 먼저 기록한다. 서버가 결과를 기록하기 전에 종료되면 화면은 편집·저장·재분석이 계속 막혔다. DB에 있던 5분 경과 후 재시도 조건을 UI가 사용할 수 없었다.

기존 코드에서 만료된 분석을 읽으면 analyzing이 그대로 반환되는 것으로 실제 DB 테스트 2건이 실패했다. 본인 초안을 다시 읽을 때 `recover_receipt_analysis`가 현재 소유권·멤버십과 행 잠금을 검사하고, 5분 경과한 실행만 failed로 복구한다. 검토 행·분석 품목·사진은 그대로 두고 실행 토큰을 지워 늦은 결과를 차단한다. 새 분석은 복구로 중단되지 않는다. 이 처리는 내부 실행 임대의 만료 정리이며, 식재료 자동 저장이나 검토 데이터 삭제가 아니다.

`expired_analysis_recovers_saved_review_and_fences_late_results_before_manual_commit`, `expired_analysis_can_retry_while_a_fresh_analysis_is_not_cancelled_by_a_read`가 RED→GREEN을 통과했다. 다른 멤버의 복구 호출 차단, 수동 저장/재분석, 기존 실행의 늦은 완료 거부를 실제 DB로 검사했다. UI 테스트는 상태 새로고침 후 기존 이름·빈 날짜를 보존하고 재분석/직접 입력을 활성화하는 것을 확인했다.

## 리뷰어가 판단을 보류한 항목과 결정

1. 실제 화면·모바일·접근성: CUA가 정책에서 차단됐다. 소스/jsdom을 실제 화면 통과로 취급하지 않고 인수 항목을 유지한다. 생략하면 시각·접근성 결함을 발견하지 못할 수 있다.
2. HTTPS 푸시·iOS 설치·알림 이동: 사용자가 검증 환경이 없다고 확인했다. 실제 기기 인수 후 릴리스한다. 지금 배포하면 플랫폼별 수신 문제를 알 수 없다.
3. 유료 공급자 재평가: 리뷰어는 호출 권한이 없는 읽기 전용 검사를 했다. 구현자가 이번 단계에서 실제 호출 2건을 별도로 통과했다. 이는 합성 fixture의 계약 검증이며 다양한 실제 사진의 품질 보장은 아니다.
4. 이미 발급한 사진 URL: 승인된 설계의 최대 60초 유효기간을 유지한다. 권한 회수 후 새 조회는 막지만, 기존 bearer URL은 남은 TTL 동안 유효할 수 있다.
5. 다른 AI 공급자·소유권 이전·냉장고 삭제·오프라인 쓰기 동기화: 승인된 범위 밖이므로 추가하지 않는다. 이 기능들은 현재 제공하지 않는다.
