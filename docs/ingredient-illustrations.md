# 식재료 일러스트

직접 편집할 수 있는 자체 제작 SVG 108종을 사용한다. 기존 15종에 93종을 추가했다. 기본 용기 1종을 제외한 107개 재료 계열에 이름·별칭을 연결한다.

## 선정 기준

한국보건산업진흥원 국민영양통계의 2023년 [다소비 식품](https://www.khidi.or.kr/kps/dhraStat/result3?gubun=sex&menuId=MENU01654&year=2023)과 [다빈도 식품](https://www.khidi.or.kr/kps/dhraStat/result4?gubun=sex&menuId=MENU01655&year=2023)을 우선 참고했다. 쌀·우유·김치·돼지고기·달걀·양파·두부·과일과 마늘·소금·간장·기름·고춧가루 같은 양념을 포함하고, 가정에서 쓰는 채소·해산물·냉동식품 등을 보완했다. 이 목록은 통계의 전체 식품 목록이나 모든 자유 입력 이름을 포괄한다는 의미는 아니다.

가까운 재료는 대표 계열 그림을 공유한다. 예를 들어 고등어·갈치는 생선, 바지락·굴은 조개, 참기름·들기름은 같은 기름병 그림을 쓴다. 그림은 목록을 알아보기 쉽게 하는 장식이며 재료의 종류나 성분을 보증하지 않는다.

## 이름 연결과 추가 방법

`src/features/inventory/ingredient-art-catalog.ts`가 파일명·대표 이름·별칭을 관리한다. 공백과 유니코드 표기를 정규화한 뒤 정확한 별칭을 먼저 찾고, 이후 가장 긴 부분 일치를 선택한다. 한 글자 이름은 일반적인 수식어·수량을 제거한 이름이 정확히 일치할 때만 사용한다. `감자전분`이 감자, `김치만두`가 김치, `멸치액젓`이 멸치로 분류되지 않게 한다. 등록하지 않은 이름은 `jar.svg`로 표시한다.

새 그림은 `public/illustrations/<asset>.svg`에 넣고 카탈로그에 추가한다. `viewBox="0 0 96 96"`, 투명 배경, 둥근 2px 외곽선, 부드러운 색 변화를 유지한다. 그라디언트 ID에는 파일명 접두사를 붙이고 외부 이미지·스크립트·폰트를 참조하지 않는다. 실제 목록의 54px 크기와 밝고 어두운 배경에서 확인한다. 별칭 겹침은 `ingredient-art-catalog.test.ts`, 컴포넌트 연결은 `ingredient-art.test.tsx`로 검사한다.
