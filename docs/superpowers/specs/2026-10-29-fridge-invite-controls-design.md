# 냉장고 선택과 초대 관리 개선

현재 냉장고 이름과 내 소유/함께 관리 역할을 같은 선택 영역에 배지로 표시한다. 기본 select 대신 접근성 combobox/listbox 패턴을 사용한다. 열기/선택/닫기와 방향키·Enter·Escape·포커스를 지원한다. pantry-context 알림 설정 링크와 내비게이션 마이페이지 탭은 제거한다. 프로필 메뉴의 마이페이지는 유지한다. 선택 영역은 컨테이너 가로 폭을 채운다.

사용자 답변: 새로 발급하는 초대만 정확히 24시간 유효하며 기존 링크의 만료 시각은 변경하지 않는다. 생성 링크와 내역의 만료 표시는 24시간제(h23)를 적용한다. 소유자가 현재 냉장고의 만료·취소·사용 완료 초대 내역을 한 번에 삭제할 수 있다. 활성 링크와 멤버십은 보존하며 서버가 삭제 대상을 판정한다. 삭제와 초대 수락 경합에서도 삭제된 토큰으로 참여할 수 없어야 한다.

비밀번호 팝업 하단에는 같은 크기의 취소·비밀번호 변경 버튼을 순서대로 배치한다. 실제 제출은 기존 인증 폼을 사용하며 저장 중 두 버튼과 상단 닫기를 비활성화한다.

로컬 수정·로컬 DB 마이그레이션과 테스트만 수행한다. 푸시/배포/클라우드 변경 금지, .env.local/.idea/기존 로컬 데이터 보존. 저장된 브라우저 로컬 접근 거부를 우회하지 않는다.
