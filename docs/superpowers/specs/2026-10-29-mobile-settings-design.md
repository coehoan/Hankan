# 마이페이지와 모바일 중심 화면 정리

사용자 요청12항목을 구현하며 명시적 배포 요청 전까지 dev push, Vercel 배포, 클라우드 DB 변경을 하지 않는다.

마이페이지를 메인 메뉴의 세 번째 탭으로 추가한다. 화면 테마는 이 탭에서만 선택하고 비밀번호 변경과 로그아웃도 이 탭으로 이동한다. 로그인/일반 페이지의 한칸 로고는 메인으로 연결하며 로그인한 앱에서는 선택한 냉장고의 목록으로 간다. 기존 인증·테마 저장과 키보드 접근성 동작은 유지한다.

모달 footer의 테마/ESC 안내, 로그인 비밀번호 분실 안내, 영문 장식 문구, fresh-tip을 제거한다. 사진 형식 등 사용에 필요한 기술 표기와 사용자 입력은 유지한다. 공통 backdrop에 블러를 추가해 다크 모드에서 배경과 패널을 구분한다.

사용자 답변: 냉장고 참여 멤버 모두 이름을 변경할 수 있다. 이름은 기존 DB와 동일하게 공백 제거 후1~80자, 제어문자 금지다. 새 RPC가 현재 멤버십을 잠그고 이름만 변경한다. 공유 멤버의 소유권/멤버 권한 변경은 허용하지 않는다. 새로고침/후속 조회로 모든 멤버에게 이름이 유지된다.

사용자 답변: 영수증 사진은 선택 후 미리보기를 보여주고 품목 확인을 눌러 진행한다. 화면에는 테두리 영역 안의 사진 업로드 버튼과 선택 이미지, 기존 muted 설명만 둔다. 품목 확인은 선택 후 별도 하단 동작이다. 브라우저 기본 촬영/갤러리 선택을 사용하는 숨긴 file input은 내부 수단이며 native input은 화면에 노출하지 않는다. Blob URL은 교체/닫기 시 해제하고10MB/JPEG·PNG·WebP 및 서버 검증/수동 재료 저장은 유지한다.

사용자 답변: 브라우저 알림 연결은 마이페이지에서 관리한다. 알림 설정 모달에는 저장된 일정이 켜졌을 때만 일정 요약을 보이고 시간대 문자열과 연결 컨트롤은 제거한다. 실제 시간 계산/저장과 수동 권한 요청 흐름은 유지한다. 마이페이지에서 일정 모달도 열 수 있게 하며 닫은 뒤 상태를 다시 읽는다.

외부 구독/새 패키지는 추가하지 않는다. 실제 카메라/사진 선택과 OS 알림 권한 UI는 기기에 따라 다르므로 로컬 테스트에서 실제 하드웨어 성공으로 집계하지 않는다.
