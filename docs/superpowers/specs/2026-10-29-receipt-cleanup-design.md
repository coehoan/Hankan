# 저장·취소 시 임시 원본 즉시 삭제

사용자 요청: 재료 저장 또는 영수증 초안 취소 시 분석용 PNG와 업로드 임시 원본을 함께 삭제한다. 저장하지 않은 초안의 기존 수명과 권한은 유지한다.

초안에 nullable staged_object_path를 서버 권한으로 기록한다. 경로는 해당 user_id/fridge_id에 속하도록 DB 제약과 서비스 입력 검사를 둔다. 사용자 입력으로 다른 파일을 지정해 삭제할 수 없게 한다. 기존 select-only RLS/RPC 권한은 변경하지 않는다.

저장/취소의 삭제 작업은 두 버킷을 모두 시도하고 모두 성공한 경우에만 cleanup_pending을 해제한다. 실패해도 이미 완료한 재료 저장/취소는 보존하며 worker가 재시도한다. 업로드 URL은2시간 유효하므로 파일은 즉시 지우되 연결 메타데이터는125분 동안 유지한다. 이 기간에 같은 URL로 재생성된 파일도 매분 정리하고, 기간이 지난 종료 초안의 연결은 해제한다. 중단된 미연결 업로드는 기존125분 정리를 유지한다.

새 nullable 필드는 기존 배포와 호환된다. 변경 전 초안에 연결 정보가 없으면 임시 파일을 추측해서 지우지 않고 기존 정리 주기를 유지한다. 데이터 초기화나 기존 사진의 임의 일괄 삭제는 하지 않는다. 테스트는 취소/저장 직후 실제 파일 부재, 다른 업로드 보존, 삭제 실패 marker+worker 복구, signed URL 재생성 후 정리, 사용자 권한을 확인한다. 전체 검사와 독립 리뷰 후 클라우드 migration, dev push, 실제 운영 합성 파일 확인까지 수행한다.
