# 한칸 식재료 관리 서비스 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 개인과 초대한 멤버가 식재료를 함께 관리하고, 영수증 확인 후 등록·요리 추천·개인별 시각의 PWA 알림을 사용하는 웹 서비스를 만든다.

**Architecture:** Next.js의 화면과 서버 기능, Supabase의 Auth·PostgreSQL·비공개 Storage로 구성한다. 재료 접근은 냉장고 멤버십으로, 영수증 초안과 설정은 사용자 소유권으로 검증한다. AI는 공급자 공통 인터페이스로 분리하며, 발송·임시 사진 정리는 웹과 별도 실행하는 Node 작업 프로세스가 맡는다.

**Tech Stack:** Next.js App Router, React, TypeScript, Supabase, Tailwind CSS, shadcn/ui, Zod, Vitest, Testing Library, pgTAP, Web Push. npm과 lockfile을 사용한다.

**Spec:** [승인된 설계](../specs/2026-10-26-hankan-design.md). 실행자는 이 문서와 설계를 모두 읽는다.

- Windows 검증 명령은 `npm.cmd`를 사용한다. 실제 DB 테스트는 폐기 가능한 로컬 Supabase에서 실행한다.

## 자기 검토와 실행 인계

- 이 서비스의 공동 관리·영수증·추천·알림은 동일한 멤버십과 재료 데이터를 사용하므로 별도 독립 프로젝트로 나누지 않는다. 각 작업의 저장·화면·발송 경계를 기준으로 검증한다.
