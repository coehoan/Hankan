# 식약처 레시피 DB 연동

- 사용자 요청: 승인된 FOODSAFETY_API_KEY로 COOKRCP01을 연결한다. 배포·push·클라우드 DB 변경은 하지 않는다.
- 서버가 HTTPS로 전체 카탈로그를 페이지당 최대 1,000건 조회하고 24시간 캐시한다. 계정·냉장고·보유 재료를 외부 API에 전송하지 않는다.
- 추천은 원본 DB 레코드만 사용한다. 재료 종류 일치, 사용 가능 묶음, 임박 기한을 기준으로 기존 분류·정렬 후 최대 12개를 반환한다. API 실패나 미설정 시 AI 생성으로 대체하지 않는다.
- 요리명·재료 원문·조리 순서를 보존하고 식약처 출처와 레코드 ID를 표시한다. 시간·인분은 null이며 화면에서 제공되지 않음을 안내한다.
- 자유 형식 재료를 보수적으로 분리한다. 달걀/계란, 다진 마늘/마늘 등의 제한된 손질 표현만 정규화한다. 부분 문자열로 다른 재료(두부/연두부, 쌀/찹쌀)를 같은 것으로 취급하지 않는다.
- 기존 인증, 동일 origin, private/no-store, 추천 후 멤버십·재료 버전 재확인을 유지한다. 서버 키는 클라이언트·응답·오류 로그에 넣지 않는다.
- 새 의존성·DB 마이그레이션은 필요 없다. 영수증 OpenAI 분석은 유지한다.
