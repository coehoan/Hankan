# 알림 저장 흐름과 전체 코드 정렬

알림 OFF 전환 시 서버에 즉시 저장하고 저장 버튼은 숨긴다. OFF 요청에는 마지막으로 저장된 시간을 사용하고, 실패하면 이전 draft로 복구하여 오류를 표시한다. ON 전환은 draft만 변경하며 시간 입력과 우측 '저장' 버튼을 표시한다. 저장 클릭 전 서버를 활성화하지 않는다. 요청 중 토글/입력/저장을 잠그고, 오프라인에서는 토글을 비활성화하여 잘못 저장된 표시를 방지한다.

비밀번호 팝업 제출 버튼명은 '변경'. 냉장고 선택 값 영역은 이름이 남은 폭을 채우고 배지가 우측에 위치한다. 펼침 표시는 중앙 정렬된 SVG 화살표이며 열리면 회전한다. 헤더 nav 영역을 제거하고 브랜드와 프로필 메뉴를 유지한다.

전체 추적 소스·테스트·스크립트·스타일·JSON/YAML 설정·SQL에 Prettier와 SQL 플러그인 버전을 고정하여 포맷한다. 2칸 들여쓰기, 세미콜론, 작은따옴표, LF를 사용한다. 개인/생성/비밀/의존성 파일(.idea, .env*, .next, .vercel, dist, work, .superpowers, node_modules, lockfile, next-env.d.ts), 생성 지침 AGENTS.md와 문서는 제외한다. SQL 함수 본문을 포함한 문자열 내용은 보존하며 포맷 전후 SQL 의미 토큰을 비교한다.

로컬 변경·검증만 수행한다. 푸시/배포/클라우드 변경 금지. 기존 환경파일과 데이터, .idea 보존. 브라우저 접근 거부를 우회하지 않는다.
