## Global Constraints

- 기존 데이터/로컬 환경파일 보존. 키와 사진을 Git·도구 출력·프로세스 인자에 노출하지 않는다.
- Production은 dev, 팀 hankan1. 추가 유료 구독 없음. Preview에는 운영 비밀 없음.
- 원본 입력 최대10MB, 비공개 staging, 서버 이미지 검증, 사용자 확인 저장 흐름 유지.
- 작업 API는 32자 이상 비밀 인증, 응답 no-store, 한 주기 await; 임대 복구와 중복 방지는 기존 DB를 사용한다.

1. 다른 사용자/냉장고의 staging 경로와 탈퇴한 멤버의 완료 요청 차단.
