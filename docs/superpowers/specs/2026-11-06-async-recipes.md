# 비동기 요리 추천

사용자가 승인한 비동기 시안의 동작을 기존 A1 앱에 연결한다. 요청은 DB에 접수하고 HTTP 202로 즉시 반환한다. 식약처와 AI를 병렬 실행하고 검증된 결과를 각각 저장해 먼저 준비된 요리를 볼 수 있게 한다. 브라우저 종료와 무관하게 worker가 처리하며 저장된 결과는 프로필의 추천 내역에서 다시 연다.

- 요청 시점의 서버 재료·사용자 날짜를 고정한다. 재료가 바뀌어도 내역을 지우지 않고 현재 목록과 다르다는 안내를 한다. 남은 양을 변경하지 않는다.
- 본인 요청만 열람하며 현재 냉장고 멤버십도 필요하다. 외부 입력으로 사용자·재료·결과를 지정할 수 없다. 공급자 실패 원문은 노출하지 않는다.
- 재시도 requestId와 진행 중 작업을 재사용한다. DB lease와 fencing token으로 중복 worker를 방지하고 중단 작업을 회수한다. 최대 3회 처리 후 실패로 종료한다.
- 응답 후 Next after로 즉시 처리하고 기존 예약 worker를 복구 경로로 사용한다. 공급자는 각각 50초 제한, 부분 결과를 보존한다.
- 완료 푸시는 기존 알림 설정 및 구독을 재검사한다. 푸시 실패가 결과 저장을 막지 않는다. 알림은 저장 결과의 안전한 앱 경로만 연다. 사용자에게 새 알림 권한을 강요하지 않는다.
- 기존 API origin/인증/RLS, 테마, 재료 그림, 레시피 상세와 출처 비표시를 유지한다. 실제 푸시·모바일 화면 검증과 자동 검사를 구분한다.
- 작업은 로컬만 수행한다. push·배포·클라우드 DB 변경·유료 AI 테스트·기존 DB reset은 하지 않는다.

필수 상태: 접수 중, 대기, 추천 중, 부분 결과, 완료, 빈 결과, 공급자 실패, 오프라인, 목록 변경, 접근 권한 상실. 화면 이탈 후에도 내역으로 복귀할 수 있다.
