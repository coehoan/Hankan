# 한칸 무료 Vercel 배포

사용자는 Vercel 직접 배포와 추가 유료 구독 없이 진행을 승인했다. 대상은 Hankan(hankan1, Hobby) 팀, coehoan/Hankan의 dev 브랜치, 기존 Supabase 클라우드다. 기본 vercel.app 주소를 사용한다. 기존 OpenAI 사용료는 유지한다.

현재 Next 웹을 Vercel Node24에 배포한다. Hobby 자체 Cron은 하루 한 번이므로 기존 Supabase의 pg_cron/pg_net이 매분 비밀 헤더로 작업 API를 호출한다. 별도 유료 worker 호스트나 Pro 업그레이드는 사용하지 않는다. 기존 DB 작업 임대·재시도·중복 방지를 유지하고 한 HTTP 요청에서 한 주기를 완료한다. 비밀은 Vault와 서버 환경변수에만 둔다.

Vercel의 4.5MB 요청 한도를 피하려고 영수증은 서버가 발급한 단일 경로 업로드 URL로 비공개 임시 버킷에 직접 올린다. 서버가 소유 사용자·냉장고와 실제 이미지(10MB, JPEG/PNG/WebP, 픽셀 제한)를 확인한 뒤 기존 PNG 정규화 및 초안 생성 흐름에 전달한다. 재료 저장은 여전히 사용자 확인 후에만 가능하다. 업로드 URL이 2시간 유효하므로 임시 파일은 생성 후 125분이 지난 것만 정리해 재사용된 URL이 고아 파일을 남기지 않게 한다. 기존 canonical 버킷의 권한과 타입 제한은 유지한다.

비교: Vercel Pro Cron은 추가 구독을 요구하므로 제외, 별도 서버는 관리 부담과 구독이 늘어 제외했다. 기존 Supabase 예약 기능 활용은 구현자 선택이다. 환경변수는 기존 파일을 공개 출력하지 않고 CLI 표준 입력으로 Production에만 전달한다. Preview에 운영 비밀을 넣지 않는다. 신규 운영 VAPID 쌍을 생성하고 전환 후 기존 로컬 cloud worker는 중지한다.

배포 전 전체 DB·단위·통합·타입·lint·빌드와 독립 리뷰, 배포 후 HTTPS 가입/로그인·사진 업로드·검증·초안·익명 작업 API 거부·인증된 작업 주기·예약 실행 확인을 수행한다. 실제 OS 푸시 권한/수신은 지원 기기에서 사용자 확인이 필요하다. 기존 사용자 데이터와 로컬 설정은 보존한다.
