# 식재료 목록의 아코디언과 더 보기

재료가 많아도 기한이 지난 재료와 먼저 먹을 재료를 빠르게 찾을 수 있게 한다. 각 구역이 차지하는 길이는 화면에서 조절한다. 재고 조회 API, 기한 분류와 정렬, 요약 수치, 요리 추천에 전달하는 재료는 기존 동작을 유지한다.

## 비교한 방식

1. **일반 목록과 검색 상태 분리.** 검색에서 구역을 열거나 더 봐도 일반 목록에 영향을 주지 않는다. 이름 검색을 시작하기 전의 상태를 그대로 복원할 수 있는 이 방식을 선택했다.
2. **일반 목록과 검색 상태 공유.** 검색에서 본 구역과 개수를 지운 뒤에도 이어 볼 수 있다. 검색 결과로 자동으로 열린 구역까지 일반 목록에 남을 수 있다.

## 일반 목록

- ‘기한 지남’, ‘먼저 먹어요’, ‘조금 더 여유 있어요’ 순서를 유지한다. 앞의 두 구역은 처음에 펼치고, 마지막 구역은 접는다. 각 구역을 독립적으로 열고 닫는다.
- 현재 검색과 보관 위치 조건을 모두 충족한 구역의 총개수를 제목 옆에 표시한다. 접어도 제목과 개수는 보인다. 일치하는 재료가 0개인 구역은 현재처럼 생략하고, 전체 결과가 0개면 기존 빈 화면과 필터 초기화를 보여준다.
- 펼친 구역은 기본 5개를 표시한다. 남은 재료가 있을 때만 ‘더 보기’를 표시하고, 누를 때마다 다음 5개까지 같은 구역의 아래에 추가한다. 마지막 재료까지 보이면 버튼을 숨긴다.
- 같은 냉장고 화면을 보는 동안에는 구역을 접었다 다시 열거나 보관 위치를 바꿔도 일반 목록의 펼침과 표시 개수 설정을 유지한다. 재고가 바뀌어 구역이 잠시 비어도 설정은 유지한다. 냉장고 전환이나 페이지 새로고침 후에는 기본값으로 시작한다.

## 이름 검색과 복원

- 이름과 보관 위치는 현재 화면에 보이는 행과 관계없이 냉장고에서 읽어 온 전체 재료에 적용한다. 기한별로 묶은 뒤 각 구역의 표시 개수를 적용한다.
- 이름 검색어에 공백을 제외한 문자가 있으면 별도의 검색 상태를 사용한다. 정규화한 검색어 또는 보관 위치가 바뀌면 일치하는 구역을 자동으로 열고 각 구역을 5개부터 보여준다. 같은 조건에서는 사용자가 구역을 접거나 더 본 상태를 유지한다. 검색 결과를 새로 받았을 때 이전에 결과가 없던 구역에 재료가 생기면 펼쳐서 표시한다.
- 검색어를 지우면 일반 목록의 구역별 펼침과 표시 개수를 복원한다. 보관 위치가 ‘전체’ 이외의 값이면 그 필터를 적용한 목록에 복원한다. 이름 검색 없이 보관 위치만 고르는 경우에는 일반 목록 상태를 계속 사용한다.
- 예를 들어 일반 목록에서 ‘먼저 먹어요’를 10개까지 보고 ‘조금 더 여유 있어요’를 접어 둔 상태에서 검색으로 여유 구역의 재료를 찾을 수 있다. 검색어를 지우면 ‘먼저 먹어요’는 최대 10개로 돌아가고 여유 구역은 다시 접힌다.

## 접근성 및 확인

구역 제목은 키보드로 작동하는 버튼으로 만들고 펼침 상태와 제어하는 영역을 보조 기술에 전달한다. ‘더 보기’의 접근 가능한 이름에는 구역 이름을 포함한다. 버튼을 누르면 키보드로 추가된 첫 재료부터 이어서 탐색할 수 있게 한다. 기존 재료 카드의 수정·삭제·남은 양 조작은 유지한다.

기본 상태와 독립 토글, 세 구역에서 5개씩 이어 보기, 개수 표시와 마지막 버튼 제거를 확인한다. 기본 표시 범위 밖의 재료 검색, 보관 위치와 이름 검색의 교집합, 검색 중 표시 개수 변경 후 검색 삭제 시 복원도 확인한다.
