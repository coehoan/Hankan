# 프로필과 설정 화면 개편

사용자 요청: 테마는 첨부 이미지처럼 시스템·라이트·다크 3분할 선택과 아이콘, 선택 상태 및 설명을 제공한다. 기존 민트 색상을 유지한다. 냉장고 소유/공유 표시는 선택 박스 이름 옆에만 표시한다.

헤더 오른쪽에는 현재 계정 이름 첫 글자의 원형 프로필을 둔다. 메뉴는 마이페이지, 냉장고 관리, 로그아웃 세 항목이다. 마이페이지의 기존 로그아웃은 제거한다. 프로필 이름은 로그인한 사용자의 profiles.display_name에서 가져오며 권한 판정에는 사용하지 않는다.

냉장고 관리는 인증된 /fridges/manage 페이지에서 현재 선택한 냉장고의 이름 변경과 멤버 관리를 제공한다. 기존 모든 멤버 이름 변경 권한과 소유자 멤버 관리 권한은 그대로 유지한다. 냉장고를 전환해도 관리 페이지에 머문다.

알림·북마크로 열었던 냉장고도 관리 화면으로 그대로 전달한다. fridgeId 쿼리는 서버가 현재 접근 가능한 목록으로 검증하고, 접근 불가/잘못된 값은 안전한 저장 선택으로 대체한다. 관리 화면에서 전환하면 같은 경로의 쿼리를 갱신한다.

재료 등록 버튼과 첫 재료 등록 버튼 모두 직접 입력·영수증 등록을 선택하는 창을 먼저 연다. 기존 직접 입력 폼과 영수증 미리보기/품목 확인 흐름으로 이어진다. 메인 툴바의 영수증 등록·멤버 관리·이름 변경은 제거한다.

마이페이지 비밀번호 변경은 가로로 긴 클릭 영역으로 표시하되 키보드에서도 작동한다. 공통 Dialog로 새 비밀번호 두 번 입력 팝업을 열며 닫기 제공, 내 냉장고로 링크는 제거한다. 성공 시 마이페이지에 머물고 확인 문구를 표시한다. 저장 중 닫기는 차단한다. 기존 직접 주소는 지원한다.

알림 받기는 iOS 형태 토글이며 접근성 switch 역할, 체크 상태 및 기존 시간 표시/조회/명시적 저장 동작을 유지한다. 브라우저 푸시 연결 UI를 되살리지 않는다.

배포·push·클라우드 변경 없이 로컬에서 구현·검증한다. .env.local과 기존 데이터, 무관한 .idea는 보존한다. 브라우저 로컬 주소 접근의 저장된 거부를 우회하지 않는다.
